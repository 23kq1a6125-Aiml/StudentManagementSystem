# Student Management System

## Project Description
A Python-based application to manage student records using Object-Oriented Programming (OOP) and SQLite database.

## Features
- Add student records
- View all student records
- Search students by ID
- Update student details
- Delete student records
- Automatically calculate student grades
- Display student statistics, including average, highest, and lowest marks
- Validate student IDs, names, and marks

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- SQLite
- SQL

## Requirements
- Python 3

SQLite is included with Python, so no separate database server or connector installation is required.

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the application:

   `python main.py`

The SQLite database file is created automatically when the application runs.

## Grade Calculation

- 60–69: C
- 0–59: D

## Project Purpose
This project demonstrates Python programming, OOP concepts, SQL database operations, input validation, CRUD operations, and student performance analysis.
